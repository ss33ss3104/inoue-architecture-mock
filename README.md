# inoue. — Design study

イノウエサトル建築計画事務所のリブランディング検討用モック。
実写写真と、写真を参考に制作したBlenderモデルによる空間体験を組み合わせた。
正式なブランド名、コピー、寸法、材種、周辺風景の確定版ではない。

## GitHub Pages

専用リポジトリの `main` ブランチに、このフォルダの内容を配置する。
Settings → Pages → Deploy from a branch → main / (root) で公開する。
トップURLから `hybrid/` へ移動する。`realistic-preview.html` は3Dの直接ビューア。
サーバー側の処理・ビルド・外部CDNは不要。

GitHub PagesのURLは一般公開。noindex / robots.txt は検索除外の指定でありアクセス制限ではない。
公開には、写真の公開利用とモック公開範囲の確認が必要。
Blender原本、図面、案件資料、他案件のデータはこの配布物に含めていない。
